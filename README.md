# Нет, это ненормально

Промолендинг тру-крайм-подкаста НЭН к Хэллоуину.

[Опубликованная версия](https://nen-net-eto-nenormalno.nancykhacha1981.chatgpt.site/) · [Подкаст на Mave](https://mave.stream/netetonenorm)

## Запуск

Статический HTML/CSS/JavaScript без сборщика и внешних runtime-зависимостей.

```sh
python3 -m http.server 4177
```

Откройте `http://localhost:4177`.

## Обновление текстов

Исходные тексты находятся в `source-copy.json`. Все 20 блоков сохранены дословно: пять полных анонсов выпусков, три биографии и остальные блоки лендинга.

```sh
python3 build.py
python3 verify_copy.py
node --check app.js
```

## Что реализовано

- Главный коллаж из реальных кинокадров и архивного фото братьев Менендесов. Источники перечислены в `assets/film-stills-sources.json` и внизу лендинга.
- Закреплённое меню, мерцание «НЕ», движение зрачков и моргание исходного SVG-логотипа.
- Перелистывание обложек при обычной прокрутке страницы. На мобильном описание и ссылка под общей стопкой синхронно меняются с выпуском; длинный анонс дочитывается прокруткой.
- Полный последовательный fallback без JavaScript и при reduced motion. Акцентные анимации приостанавливаются вне экрана и в скрытой вкладке.
- Локальные Jost, обложки, портреты, видео- и аудиотизер с waveform. Лицензия Jost — `assets/Jost-OFL.txt`.
- Отдельные ссылки на все пять эпизодов Mave, доступные якоря и клавиатурная навигация.

Каталог `tools/` сохранён из основной ветки. Актуальный HTML этой версии генерируется корневым `build.py`.
